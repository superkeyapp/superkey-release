# 超级快捷键 下载

超级快捷键是一款开箱即用的 Windows 效率工具，用快捷键、鼠标手势、屏幕边缘等方式，让常用操作一步完成。

**下载**：到本页右侧的 [Releases](https://github.com/superkeyapp/superkey-release/releases) 下载最新版本：

| 文件 | 说明 |
|---|---|
| `SuperKey-<版本>-x64-Setup.exe` | 安装包（推荐），双击安装 |
| `SuperKey-<版本>-x64-Portable.zip` | 便携版，解压即用 |
| `SuperKey-Classic-<版本>-x64-Setup.exe` / `-Portable.zip` | 经典版：系统原生控件的界面，单个程序，不用装 .NET |

支持 Windows 10、11（64 位）。功能介绍、使用文档：[超级快捷键官网](https://superkeyapp.github.io)。
